Respostas — Questões de CSS

1. Parágrafos com texto azul e tamanho 16px

Foi utilizado um seletor de tipo, pois ele seleciona todos os elementos <p> existentes no documento.

p {
  color: blue;
  font-size: 16px;
}

2. Botões que possuem a classe .confirmar

Nesse caso, foi usado um seletor de elemento junto com classe, aplicando o estilo somente aos botões que tenham a classe indicada.

button.confirmar {
  background-color: green;
  color: white;
}

3. Área com id="menuPrincipal"

O seletor usado é o seletor de ID, que serve para identificar e estilizar um elemento específico da página.

#menuPrincipal {
  text-align: center;
}

4. Parágrafos localizados dentro de .conteudo

Foi aplicado um seletor descendente, que alcança todos os parágrafos dentro do elemento com a classe .conteudo, mesmo que estejam em níveis internos.

.conteudo p {
  font-weight: bold;
}

5. Uso de position: relative

A propriedade position: relative mantém o elemento no fluxo normal da página, mas permite mudar sua posição visual usando top, right, bottom ou left.

p {
  position: relative;
  top: 10px;   /* desloca para baixo */
  left: 20px;  /* desloca para a direita */
}

6. Banner preso no topo da tela

O valor utilizado é position: fixed, pois ele fixa o elemento em relação à janela do navegador, mantendo-o visível durante a rolagem.

.banner {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  z-index: 1000;
}

7. Campos obrigatórios com borda vermelha

Foi usado um seletor de classe, aplicando a borda vermelha a todos os elementos que possuírem a classe .obrigatorio.

.obrigatorio {
  border: 2px solid red;
}

8. Diferença entre div p e div > p

div p seleciona qualquer parágrafo dentro de uma div, mesmo que esteja dentro de outros elementos.

div > p seleciona apenas os parágrafos que são filhos diretos da div.

div > p {
  color: green;
}

9. Links que mudam ao passar o mouse

A funcionalidade usada é uma pseudo-classe. O :hover aplica um estilo quando o cursor está sobre o link.

a:hover {
  color: orange;
}

10. Retirar margens padrão dos elementos

Foi usado o seletor universal (*), que seleciona todos os elementos HTML da página.

* {
  margin: 0;
}
