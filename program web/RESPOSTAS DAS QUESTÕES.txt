questão 2) Explique as diferenças existentes entre "seletores de classe" e "seletores de ID".

R:Classe (.) pode ser usada em vários elementos e serve para repetir estilos; já o ID (#) deve ser único na página e serve para um elemento específico; além disso, o ID tem prioridade maior que a classe, ou seja, seu estilo sobrescreve o da classe quando há conflito.


questão 3) Suponha, uma folha de estilo externa com as seguintes propriedades para o seletor h2:
h2 {
color: #FFCC00;
text-align: center;
font: italic 9pt Verdana, Sans-serif;
}
e, uma folha de estilo interna com as seguintes propriedades para o seletor h2:
h2 {
color: #FFCC00;
text-align: center;
font: italic 10pt Verdana, Sans-serif;
}
Se ambas as páginas estiverem vinculadas ao documento, como será resolvido o conflito no tamanho das letras para <h2>?
No exemplo acima o elemento <h2> terá que tamanho?

R:Quando há conflito entre CSS externo e interno, o **CSS interno tem prioridade maior**; como apenas o tamanho da fonte é diferente (9pt no externo e 10pt no interno), o valor do interno sobrescreve o externo, então o `<h2>` ficará com **tamanho 10pt**.
