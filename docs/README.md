## **2.7 Tema 7 — Sistema de Farmácia (Vitrine e Gestão) (Eduardo Luiz, Nicolas, Franco)**

Um site voltado para uma farmácia fictícia, integrando três pilares principais: gestão de estoque de medicamentos, cálculo de dosagens e fluxo de vendas. O site funciona como uma interface completa para atendentes e farmacêuticos, apresentando catálogo de produtos, consulta de medicamentos, controle de estoque e geração de documentos como receitas.

---

**Sugestões de páginas:**

- Home — painel resumo com alertas de estoque baixo, vendas do dia, atalhos para as principais seções e identidade visual da farmácia.
- Catálogo de Produtos — grade de medicamentos com foto, nome comercial, genérico, laboratório, preço e disponibilidade em estoque.
- Ficha do Medicamento — página de detalhe com informações completas: composição, indicações, contraindicações, modo de uso, tipo (tarja vermelha/preta, genérico, etc.) e necessidade de receita.
- Controle de Estoque — tabela com todos os produtos, quantidade em estoque, data de validade, nível mínimo configurado e alertas de reposição. Inclui formulário para entrada/saída de itens.
- Vendas / Carrinho — interface para registrar uma venda, selecionar produtos, calcular total e verificar se o medicamento exige receita. Pode gerar um comprovante de venda fictício.
- Geração de Receita — formulário para preencher os dados de uma receita médica fictícia (paciente, médico, CRM, medicamento, dosagem e posologia) com visualização formatada para impressão.
- Contato / SAC — formulário de atendimento ao cliente, horários de funcionamento e localização da farmácia fictícia.
