# 💊 FarmaSys — Sistema de Gestão de Farmácia

Sistema web para gerenciamento de farmácia, desenvolvido como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas.

---

## 📋 Sobre o projeto

O FarmaSys é um sistema de gestão voltado para o ambiente interno de uma farmácia. O objetivo é centralizar o controle de vendas, estoque, validade de produtos e atendimento ao cliente em uma interface simples e funcional para os atendentes.

---

## ✅ Funcionalidades

- [x] Dashboard com métricas do turno (vendas, faturamento, clientes)
- [x] Alertas de estoque baixo e produtos próximos ao vencimento
- [x] Ranking de produtos mais vendidos no dia
- [x] Histórico de últimas vendas
- [x] Catálogo de produtos
- [x] Controle de estoque completo
- [x] Geração de receitas
- [x] Carrinho de compras

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- Font Awesome 6 (ícones via CDN)

---

## 🚀 Como rodar

Não há dependências ou build necessário — é HTML puro.

```bash
# Clone o repositório
git clone https://github.com/aKynoS2/projeto_farmacia.git

# Acesse a pasta do projeto
cd projeto_farmacia

# Abra o arquivo principal no navegador
# Basta abrir o arquivo home.html diretamente,
# ou usar uma extensão como Live Server (VS Code)
```
